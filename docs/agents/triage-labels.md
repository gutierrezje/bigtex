## Triage label vocabulary

These skills assume a 5-state triage workflow. This repo uses the **default label strings**:

- `needs-triage` — maintainer needs to evaluate
- `needs-info` — waiting on reporter
- `ready-for-agent` — fully specified and AFK-ready
- `ready-for-human` — needs human implementation
- `wontfix` — will not be actioned

If you later adopt different label names, update this file so automated triage doesn’t create duplicates.
