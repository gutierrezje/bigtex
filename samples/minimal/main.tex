\section{Why this exists}

BigTeX is a prototype for an agent-first desktop LaTeX editor. The editing
surface stays local and fast, compilation happens out of the renderer process,
and agent output is reviewed before it changes project files.

\section{Try the loop}

Edit this file, save it, compile, then ask the agent to improve a paragraph or
fix a compiler diagnostic. If the agent returns a unified diff, BigTeX can
apply it explicitly.
