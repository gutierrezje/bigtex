\section{Checklist}
Use this list when demoing BigTeX:
\begin{itemize}
  \item Compile once with errors present; confirm Problems lists file:line items.
  \item Fix the math error, recompile; PDF should build with warnings remaining.
  \item Resolve undefined \verb|\ref| and \verb|\cite| warnings in \texttt{references.tex}.
  \item Tweak figure width and the long word in \texttt{layout.tex} to clear overfull boxes.
  \item Run agent handoff on a warning row; confirm composer prefill and patch flow.
\end{itemize}
